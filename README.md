# Цифровые учебники

Стартовая страница — книжная полка на однотонном светлом фоне, без клетки и тетрадных полей. С занятиями общие шрифты Neucha и Andika и синие кнопки. Фоны обложек однотонные; книги сохраняют спокойную охристую, зелёную, терракотовую и синюю палитру. Тетрадная клетка остаётся внутри учебника. Кнопки занятий имеют высоту 64 px, текстовые подписи — размер не меньше 16 px. Доступная «Арифметика · 1 класс» открывает оглавление или продолжает сохранённое занятие; будущие учебники отмечены «В планах». Будущие книги стоят на полке по две на телефонах и небольших планшетах, по три — на широком экране.

Чтобы включить поддержку проекта, укажите публичный адрес своей страницы Patreon в `PROJECT_PATREON_URL` в [`src/content/library.ts`](src/content/library.ts). Пока адрес пуст, кнопка поддержки недоступна и подписана «Patreon — скоро». Там же перечислены будущие книги. Обложка арифметики имеет отдельную охристую композицию из наших обновлённых иллюстраций: дети у школы (`p003_school_children`), мячи (`p003_balls_bigger_smaller`) и карандаши (`p003_pencils_longer_shorter`). Исходники иллюстраций не изменены; исходный PNG хранится в `assets/library/`, веб-версия использует WebP.

Шкала поддержки показывает 12 500 ₽ из 60 000 ₽. Суммы обновляются вручную через `PROJECT_FUNDING` в том же файле; подключение к платёжному сервису не требуется. Сброс ответов доступен только внутри открытого учебника через раздел «Родителям» и отдельное подтверждение.

Проверка библиотеки после веб-сборки: `node scripts/run-browser-tests.cjs scripts/library-smoke.cjs`. Она проверяет семь размеров экрана, переходы, отсутствие обрезанных обложек, шкалу сбора, восстановление прогресса после перезагрузки и доступность сброса только внутри учебника. Результаты и снимки сохраняются в системную временную папку.

Главная страница доступна на русском, английском, немецком, французском, испанском и итальянском. Крупное вертикальное колесо поддерживает прокрутку, нажатие на язык, кнопки и клавиши ↑/↓, Home/End. Выбор сохраняется на устройстве отдельно от ответов. Содержание самого учебника остаётся на русском — это указано на карточке для других языков. Общая справка для родителей на главной переведена и открывается сразу; защита сброса внутри учебника сохранена.

Добавление языка: внесите его код и собственное название в `libraryLanguages`, затем полный перевод в `libraryCopy` в [`src/localization/library.ts`](src/localization/library.ts). Типы проверят наличие всех подписей и предметов. Форматируемые строки используют именованные поля `{raised}`, `{goal}`, `{completed}`, `{total}`. Проверка: `node scripts/run-browser-tests.cjs scripts/library-localization-smoke.cjs` (все шесть языков на четырёх ширинах, сохранение выбора, клавиатура и прокрутка).

Тестовое Expo-приложение по всему учебнику «Арифметика для 1 класса», А. С. Пчёлко, Г. Б. Поляк, 1959: **144 страницы, все 892 номера заданий, 488 иллюстраций**. Оригиналы страниц доступны из занятия. Учебные занятия — страницы PDF 3–142 (140 страниц). Обложка, оглавление и выходные данные доступны отдельно на главной; титульный лист исключён из занятий.

## Запуск

Веб-версия: [uchebnik-v2.onrender.com](https://uchebnik-v2.onrender.com). Параметры публикации и обновления: [Render](docs/DEPLOY_RENDER.md).

Node.js 22.13 или новее:

```sh
npm ci
npm start
```

Для браузера: `npm run web`. Для симуляторов: `npm run ios` / `npm run android`. Нативный запуск требует клиента, совместимого с установленным Expo SDK 57. Запуск на физическом телефоне пока не проверен.

Статический предпросмотр:

```sh
npm run export:web
python3 -m http.server 8081 --bind 127.0.0.1 --directory dist
```

[Открыть локальную версию](http://127.0.0.1:8081).

## Режим сверки для разработки

На ветке `feature/debug-source-view` команда `npm run web:debug` запускает приложение на порту 8082: задание слева, исходная страница PDF справа. Можно передать другой порт: `npm run web:debug -- --port 8090`. В production код панели удаляется, даже если передан debug-флаг. [Инструкция и проверки](docs/DEBUG_SOURCE_VIEW.md).

## Возможности

- Разделы курса, поиск страницы или задания (`№ 500`), свободная навигация и сохранение ответов.
- Выбор объектов и цифр на иллюстрациях первых страниц; отдельные поля для примеров, вопросов задачи и неизвестных слагаемых.
- Монеты, предметный счёт, состав числа, десятки и единицы, распределение поровну, числовые последовательности, таблица сотни и поиск страниц.
- Составление примеров и задач по заданной структуре: ребёнок выбирает числа и тему; проверяются ограничения и вычисления. Несколько допустимых решений принимаются.
- Учебные модели линейки, весов, мерок жидкости и игра с мишенью. Физические размеры предметов ребёнка приложение не измеряет. Редакторские параметры виртуальных моделей отмечены отдельно от оригинала.
- Палочки кладутся на образец во всех 12 заданиях на составление фигур — переносом или двумя нажатиями (на палочку, затем на пунктир); палочка сама ложится вдоль пунктира, лишнюю можно убрать. На странице с шашками ребёнок сам отмечает парные предметы. Счёты заменены карточками с жетонами.
- 32 графических блока с проверкой траектории. Чёрточки лежат на сторонах клеток, квадраты и ёлочки привязаны к пересечениям сетки; наклонные палочки на странице 5 имеют размер 1×2 клетки. Замкнутые фигуры можно начинать с любого места и вести в обе стороны. Палитра: чёрный, красный, синий. Прописные цифры перенесены по сканам, включая наклон «1», завитки «2» и непрерывную «8». [Наложение на оригиналы](docs/handwritten-digit-overlay.png).
- Подсказки, отмена штриха и восстановление занятия. «Дальше» не выдаёт нерешённое упражнение за выполненное.
- На экране задания — только задание: выход и «Как это сделать?» сверху, «Назад» и «Дальше» под листом, на одном месте на всех шагах. Шаги страницы и скан открываются по «Шаг 3 из 8». Страница заканчивается экраном «Готово!» с выбором: продолжить или закончить. Раздел для родителей закрыт вопросом для взрослых. [Проверка по детским правилам](review/review_3_ux_audit.md).

Это прототип, а не аттестованная обучающая система. Автоматическая проверка открытых задач оценивает математическую структуру, а не качество свободного рассказа. Рисование проверяет обведение заданного образца, а не произвольный почерк. Проверка с ребёнком и запуск на физическом iOS/Android ещё нужны. Полный охват номеров не заменяет повторную редакторскую сверку каждого подпункта со сканом.

## Контент и разработка

`textbook/` содержит исходный PDF, сканы, извлечённые PNG и подробное ТЗ по страницам. Эти файлы не изменены. `assets/book/` — оптимизированные ресурсы приложения, около 60 МБ. Для web нет Service Worker: холодный запуск без сервера не гарантируется.

- `src/content/book.ts` — начальные страницы и объединение курса.
- `src/content/fullBookData.ts` — сгенерированные задания страниц 11–144.
- `scripts/content/extract.py` — чтение Markdown-спецификаций.
- `scripts/content/build_course.py`, `early_pages.py`, `overrides.py` — правила переноса, ручные задания и редакторские исключения.
- `src/content/fullBook.ts`, `tracing.ts` — построение фигур и геометрия прописей.
- `src/components/CourseTask.tsx` — новые взаимодействия; `src/lib/courseAssessment.ts` — их проверка.

Перегенерация:

```sh
python3 scripts/content/extract.py
python3 scripts/content/build_course.py
npm run assets
```

При неопределённом соответствии номерного задания генератор завершается ошибкой. Старый ключ AsyncStorage сохранён намеренно: прогресс первых десяти страниц переносится. Изменённые прописи повторно проверяются по новой геометрии.
