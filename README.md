# Арифметика · Первые шаги

Тестовое Expo-приложение по первым **10 страницам PDF** «Арифметика для 1 класса», А. С. Пчёлко, Г. Б. Поляк, 1959. Страницы 1–2 — обложка и титул, 3–10 — учебный материал. Внутри **82 шага**, **65 иллюстраций** и оригиналы всех десяти страниц.

## Запуск

Нужен Node.js 22.13 или новее. Зависимости закреплены в `package-lock.json`.

```sh
npm ci
npm start
```

Отсканировать QR-код совместимым с SDK 57 клиентом Expo Go на телефоне в той же сети. Для браузера:

```sh
npm run web
```

Для установленного симулятора: `npm run ios` / `npm run android`. Совместимость приложения с реальным устройством ещё нужно проверить; сборка JS-пакета не заменяет такой запуск.

Статический предпросмотр:

```sh
npm run export:web
python3 -m http.server 8081 --bind 127.0.0.1 --directory dist
```

Открыть [локальную версию](http://127.0.0.1:8081). Сервер работает, пока запущена команда. Это локальная версия, не публичная публикация.

## Что уже работает

- Каталог всех десяти страниц и свободный переход между 82 шагами. На страницах знакомства одна кнопка «Дальше»; отдельного подтверждения просмотра нет. Невыполненные упражнения можно открыть позже, переход не выдаёт их за решённые.
- **34 задания с действием на рисунке:** мячи, карандаши, положения на досках, поиск цифр на обложке и монетах, выбор карточки с цифрой, отметка предметов при счёте. Нажатие повторно снимает отметку. Для наклонных предметов используются многоугольные зоны.
- Числовые ответы проверяются сразу после выбора цифры. Палочки, кружки и наборы сторон фигур проверяются отдельной кнопкой.
- **16 графических заданий с автоматической проверкой обведения:** чёрточки, точки, волны, кольца, крючки, квадраты, ёлочки, цифры 1–3 и простые предметные рисунки с подписью.
- Клетчатое поле сохраняет квадратные клетки на телефоне и компьютере. Пунктир, начало и конец линии, подходящий цвет и пошаговый переход подсказывают действие. Длинные образцы разделены на листы без потери повторений.
- Проверяются форма, расположение, направление, длина и цвет движения; для точки — размер и положение. Небольшие отклонения допускаются. Это локальная геометрическая проверка **заданного образца**, а не распознавание произвольного почерка или рисунка.
- Подсказки, повторная попытка, озвучивание системным голосом, увеличиваемый оригинал страницы.
- Локальное сохранение ответов, законченных элементов прописи и последнего шага; отмена последнего штриха; сброс прогресса с подтверждением.
- Мешки на странице 5 остаются свободной тренировкой без строгой проверки числа: перекрытия в скане не позволяют задать однозначный ответ. Ребёнок может продолжить самостоятельно, без кнопки взрослого.

Контент и иллюстрации входят в приложение; сервера и аккаунта нет. На нативном устройстве учебные ресурсы доступны локально. Для web при первом открытии нужна доступность сервера; Service Worker и гарантированный холодный запуск web без сети пока не реализованы. Русский голос и работа системного синтеза без сети зависят от устройства.

## Содержание и архитектура

| Путь | Назначение |
|---|---|
| `App.tsx` | Каталог, занятие, оригинал, родительский экран |
| `src/content/book.ts` | 82 блока, вопросы, точные ответы, рубрики и ссылки на источник |
| `src/content/types.ts` | Разделённые типы чтения, числа, выбора, предметной модели, рисунка и фигуры |
| `src/content/childInteractions.ts` | Зоны на иллюстрациях и адаптация вопросов для ребёнка |
| `src/content/tracing.ts` | Поэлементные образцы прописей в координатах клеток |
| `src/lib/tracing.ts` | Геометрическая проверка движений и восстановление позиции |
| `src/content/assets.ts` | Статические `require()` ресурсов для Metro |
| `src/lib/assessment.ts` | Независимая проверка ответов и восстановление прогресса |
| `src/lib/storage.ts` | AsyncStorage, версионированный ключ, последовательная очередь записи |
| `src/components/` | Компоненты заданий, рисования, фигур и иллюстраций |
| `assets/book/` | Оптимизированные копии ресурсов; 6,1 МБ |
| `textbook/` | Исходные сканы, извлечённые PNG и полное ТЗ учебника |
| `docs/` | Покрытие, протокол проверки, скриншоты |

Каждая страница хранит `sourceDoc`; каждый блок — стабильный ID и ссылки на исходные иллюстрации. Дословные условия сохранены в данных. Интерфейс показывает короткий вопрос ребёнку, без технических комментариев ТЗ. Иллюстрации имеют размеченные области, не попиксельные маски; свободного перетаскивания и общего распознавания рисунков нет. Старые отметки просмотра не засчитываются за новые задания на нажатие; прописи пересчитываются по фактическим движениям.

Исходный соседний прототип `../Uchebnik` изучен как контекст. Эта версия самостоятельна и не требует его файлов или `node_modules`.

## Проверки

```sh
npm run typecheck
npm test
npx expo install --check
npm run export:web
npx expo export --platform ios --platform android --output-dir /tmp/uchebnik-native-export
```

Браузерная проверка требует Chrome, Playwright и запущенный статический сервер на 8081. Скрипт запускает отдельный временный браузерный профиль:

```sh
# PLAYWRIGHT_MODULE — путь к установленному модулю playwright;
# если он установлен в node_modules проекта, переменная не нужна.
PLAYWRIGHT_MODULE=/path/to/node_modules/playwright node scripts/browser-smoke.cjs
```
