# Знакомство с количеством вместо поиска цифры

16 сентября 2026. Исправлены PDF 7 (`p007-block07`), PDF 8 (`p008-block08`), PDF 10 (`p010-block06`).

В оригинале предметы, точки, кружки и цифра расположены рядом как разные представления одного количества. В предыдущей версии адаптация превращала вводный материал в поиск цифры: нажатие на точку считалось неверным ответом. Это противоречило смыслу страницы.

Теперь ребёнок касается каждого представления и видит подпись количества. Например, один гриб, одна белка, один ёж, одна точка, один кружок и цифра 1 связаны общим объяснением. Все картинки допустимы; нет лишнего предмета, который нужно отвергнуть. Число 2 также показано двумя современными жетонами вместо счётов, как ранее требовалось для проекта. Сцена с велосипедом подписана «Два колеса», а не «Два велосипеда».

Онбординг по очереди указывает на реальные карточки и объясняет связь предметов с числом. Для 1, 2 и 3 сохраняются отдельные первые знакомства. После подсказки карточки остаются неотмеченными: их касается сам ребёнок. Повторный осмотр не отменяет отметку. Старое сохранение выбора единственной цифры не завершает новое знакомство автоматически.

Это объяснение с активным рассматриванием, а не тест понимания абстракции: касания всех изображений не доказывают, что ребёнок усвоил понятие. При ручной проверке попросите найти ещё один/два/три предмета вокруг себя и объяснить, что общего у разных рисунков. Не добавляйте такой вопрос автоматически как обязательное упражнение из книги.

Аудит кода подтвердил: формулировка «Найди цифру… Нажми на карточку с цифрой» существовала именно в этих трёх заданиях. Поиск спрятанных цифр на титульной иллюстрации сохранён. Другие страницы не объявлены полностью проверенными по этому педагогическому критерию.
