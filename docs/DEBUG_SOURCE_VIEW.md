# Сверка с оригиналом удалена из приложения

Из учебного интерфейса убраны кнопка «Страница в книге», окно просмотра исходного скана и отдельная панель сравнения. Список шагов и проверка ответов в упражнениях сохранены.

Команды `web:debug` и `test:debug` удалены. Старый флаг `EXPO_PUBLIC_SOURCE_DEBUG` больше не включает никаких элементов сверки. Для запуска используйте `npm run web`.

Исходные PDF, сканы и иллюстрации остаются в проекте для редакторской работы. Изображения, которые являются частью самих заданий, сохранены.

Проверка `npm run test:release-guard` собирает web, iOS и Android с намеренно включённым старым флагом и проверяет отсутствие элементов сверки в сборках. Браузерные сценарии `library-smoke.cjs` и `lesson-frame-smoke.cjs` проверяют, что список шагов работает без кнопки открытия оригинала.
