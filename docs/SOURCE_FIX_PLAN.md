# Исправления по сверке с учебником

15.09.2026. Пользователь разрешил исправить неверные ответы, потерянные подвопросы, подменённые сюжеты и замену рисования/выкладывания числовым вводом.

Исходный реестр: [MANUAL_SOURCE_REVIEW.md](MANUAL_SOURCE_REVIEW.md). Согласованные ранее детские жесты, палитра и современные счётные средства сохраняются. Спорные интерпретации без подтверждения сканом не превращаются в новые жёсткие ответы.

## Решение

1. Исправить источники генерации, границы упражнений и ошибочные MD-ключи. Контрольные значения тестов брать независимо со сканов.
2. Восстановить ранние сюжеты и все вопросы, названия рисуемых предметов, связь иллюстрации с действием; убрать обязательные повторы, которых нет в источнике.
3. Для практических заданий добавить общий блок с последовательными действиями. Ребёнок перетаскивает предметы, рисует на клетчатом поле или собирает фигуры. Числовые ответы дополняют выполненные действия, но не заменяют их.
4. Сохранять выполненные этапы; после изменения раннего этапа перепроверять зависимые. Старый числовой ответ не засчитывает новую практическую задачу.
5. Проверить правильный/неправильный/неполный ответ, ошибку и повтор, точное количество подпунктов, геометрию, сохранение и браузерные жесты. Затем запустить общий набор проверок и записать фактический результат.

## Владение файлами при параллельной работе

- Ответы: `build_course.py`, `extract.py`, `overrides.py`, ошибочные описания страниц, отдельные регрессионные тесты.
- Ранние страницы: `early_pages.py`, `book.ts`, отдельные тесты.
- Практический контент: новый `practical_tasks.py` с заданиями по сканам и отдельные тесты.
- Интегратор: типы практических заданий, UI, проверка действий, прогресс, браузерная регрессия и итоговый отчёт.

Генерация общих данных выполняется последовательно после интеграции. Прежние незакоммиченные изменения сохраняются. Коммит и push в текущий запрос не входят.
