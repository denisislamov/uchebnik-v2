# Ручная проверка приложения

Для Дениса. Версия прототипа: 9 сентября 2026 года. Проверяем весь учебник: 144 страницы PDF, задания № 1–892. Номер страницы в приложении — номер листа PDF, он может отличаться от печатного номера.

## Подготовка

1. Откройте [приложение](http://127.0.0.1:8081/) при работающем локальном сервере. После обновления кода перезагрузите вкладку. Для запуска из репозитория: `npm ci`, `npm run export:web`, затем `python3 -m http.server 8081 --bind 127.0.0.1 --directory dist`.
2. Для чистого прогона используйте отдельный профиль браузера или приватное окно. Не удаляйте сохранённый прогресс ребёнка. Проверку восстановления делайте в том же окне: приватный профиль обычно удаляется при его закрытии.
3. Основной прогон: компьютер с мышью. Повторный: настоящий телефон с пальцем. Изменение ширины окна до 390 px проверяет вёрстку, но не заменяет телефон.
4. Запишите дату, Git-коммит (`git rev-parse --short HEAD`), браузер, устройство и размер экрана.

## Быстрый прогон, 15–20 минут

| Действие | Ожидаемый результат |
|---|---|
| На главной найти страницу 3 и открыть её | Открывается «Больше или меньше?», доступны все шаги и оригинал |
| В большом мяче нажать маленький, проверить; затем выбрать большой | Неправильный выбор не даёт успеха. Большой мяч выбирается нажатием на сам рисунок и принимается |
| Нажать выбранный предмет повторно | Выделение снимается; состояние проверки обновляется |
| На одной из первых страниц открыть поиск цифры, нажать неверный знак, затем нужный | Засчитывается нужная цифра на картинке, а не любое нажатие в её окрестности |
| На странице 3 открыть «Проведи чёрточку» | Шаблон чёрной линии лежит на горизонтальной стороне одной клетки; точка имеет свой образец |
| Провести короткую часть линии или линию между рядами | Элемент не засчитывается; остаётся возможность исправить |
| Обвести нужным цветом, поставить точку; отменить последний элемент и повторить | Принимаются корректные действия, отмена уменьшает прогресс, повтор восстанавливает его |
| Нажать «Дальше» в нерешённом шаге, вернуться | Навигация работает, но упражнение не стало решённым само собой |
| Найти № 49 и составить задачу: тема «рубли», 1 + 3, результат 5, затем 4 | Ошибка 5 не принимается, 4 принимается |
| Найти № 642 | Есть 14 полей, включая вычисления из рамки. Не пропущено 18 : 2 |
| Найти № 798 | Представлены и пропуски, и обычные примеры третьего столбика |
| Обновить страницу после ответа | Восстановлены занятие и ответ. Изменение верного ответа на неверный снимает успех |
| На телефоне пройти выбор и несколько штрихов | Кнопки доступны, нет горизонтального обрезания; при рисовании лист не прокручивается вместо штриха |

## Проверка каждого способа ответа

В каждом проверяемом задании сначала оставьте ответ пустым, затем дайте заведомо неверный, затем верный. Успех должен появиться только после выполнения всех обязательных частей. После успеха измените ответ и убедитесь, что старый успех не сохраняется безусловно.

| Способ | Что проверить |
|---|---|
| Число и несколько полей | Каждому подпункту соответствует поле; ответы вычислить независимо от приложения; пропуск одного поля не принимается |
| Выбор на картинке | Нажимать по самому предмету, фону, соседнему предмету и краям. Выбор можно снять. В заданиях с несколькими объектами одного недостаточно |
| Счёт предметов и группы | Добавление/убавление, достижение цели, лишний предмет, распределение поровну и неполная группа |
| Монеты | Несколько допустимых наборов одной суммы, сумма меньше и больше нужной; удаление монеты |
| Состав числа, десятки/единицы | Обе части и итог соответствуют условию; например № 202: один десяток и четыре единицы дают 14 |
| Открытые примеры | Два разных верных решения принимаются; повтор одного решения и нарушение заданного действия не принимаются |
| Составление задачи | Выбрать тему и числа, проверить связь результата с действием. Приложение проверяет структуру, но не связность свободного рассказа |
| Линейка, весы, жидкость | Следовать указанным виртуальным единицам; проверить меньший, точный и больший результат. В № 491 пять стаканов по 200 мл дают литр |
| Таблица сотни и поиск страниц | Нажатия по нужным числам, лишнее число, снятие выбора; № 737 открывает скан выбранной страницы |
| Сравнение с рисунком | Числа/разность и рисунок обязательны; только числового ответа недостаточно. № 298 и 353 — именно столбики клеток |
| Мишень | Сумма попаданий изменяется, достижение цели засчитывается, отмена обновляет результат |
| Обзор и чтение | Видны исходные изображения и текст, работает «Дальше». Нет взрослой кнопки «Мы рассмотрели» или отдельной кнопки «Пропустить» |
| Озвучивание | Русская речь соответствует текущему условию; повтор и переход между заданиями не создают мешающих друг другу фраз. Проверить на каждом устройстве отдельно |

## Особое внимание: прописи и клетки

Откройте оригинал рядом с заданием. Сравните направление, размер в клетках, число повторов, цвет, порядок, форму и место элемента относительно линий. Измените ширину окна: клетки должны оставаться квадратными, образец — привязанным к той же сетке.

| Страница / задание | Контроль |
|---|---|
| 3, чёрточки | Длина одной стороны клетки, горизонтальная линия на сетке; не посередине клетки |
| 4, квадраты и диагонали | Квадрат 1×1 клетка, стороны на сетке, диагонали соединяют углы |
| 5, наклонные палочки | Наклон проходит через прямоугольник 1×2 клетки; направление сравнить со сканом |
| 6, круги, крючки, волны | Круг занимает клетку, крючок — две по высоте; 12 чёрных волн без добавленных зелёных точек |
| 9, прямоугольники | Общая нижняя линия и внутренние разделители клеток |
| 11, ёлочки | Ветки соединяют углы клеток, не произвольные точки между линиями |
| 12, флажки | Полотнище 2×1 клетки с вырезом, последний флажок зеркальный |
| № 298 и 353 | Столбики вертикальные, непрерывные и начинаются от общей нижней линии; 20 клеток не переносятся в горизонтальный ряд |
| Остальные прописи | Все элементы и цвета сверить с соответствующим оригиналом, пройти все листы шаблона, а не только первый |

Для открытого штриха должны быть видны синие стрелки по направлению движения и пояснение их значения. Для замкнутой фигуры стрелок и фиксированной точки начала нет: начните с середины любой стороны, затем повторите в обратном направлении. Обе корректные попытки должны приниматься. После принятия штриха подсказка переходит к следующему; после отмены возвращается. Для точки стрелок нет: написано, что нужно коснуться кружка без движения.

Для каждого типа попробуйте правильный штрих, половину штриха, неверный цвет, смещение на половину клетки и касание без движения. Неверные варианты не должны давать успех. Проверка допускает небольшую неточность руки: идеальной геометрической точности от ребёнка не требуется. Обведите несколько элементов пальцем; если правильные попытки ребёнка регулярно отвергаются, это отдельный дефект допуска.

## Полная сверка 144 страниц

Используйте [постраничный чек-лист](MANUAL_PAGE_CHECKLIST.md). Для каждой страницы:

1. Прочитайте её исходное ТЗ и посмотрите скан: ссылки есть в строке чек-листа.
2. Откройте страницу через поиск, пройдите **каждый шаг и каждый подпункт**, а не только каждый номер задания.
3. Сверьте условие, числа, знаки действий, подписи, изображения, таблицы, порядок частей и редакторские адаптации. Наличие номера ещё не означает полноту задания.
4. Самостоятельно решите примеры по оригиналу. Проверьте пустой, неверный и верный ответ; исправление после проверки, возврат, перезагрузку.
5. Повторите взаимодействия на телефоне. Для длинных страниц проверьте нижние поля и кнопки.
6. Поставьте отметку только за фактически выполненную проверку; записывайте найденные дефекты. Автотесты не заполняют этот человеческий чек-лист.

Страницы с продолжением № 331, 489 и 887 проверяйте совместно с соседней. Виртуальные измерения и открытые задания имеют адаптации — сверяйтесь с [описанием покрытия](CONTENT_COVERAGE.md).

## Как сообщить об ошибке

Скопируйте шаблон:

```text
Коммит / дата:
Устройство / браузер:
Страница PDF / № задания / название шага:
Ссылка на исходное ТЗ:
Что нажал или нарисовал (по шагам):
Ожидал по оригиналу:
Получилось:
Повторяется после перезагрузки: да / нет
Скриншот или запись экрана:
```

Критично: потеря прогресса, принятие неверного ответа, отказ корректному ответу, пропущенный подпункт, неверная геометрия относительно клеток, невозможность действовать без взрослого. Нативные устройства и участие ребёнка остаются отдельными этапами приёмки даже при зелёных автотестах.

## Дополнительный прогон по последним замечаниям

1. На главной открыть обложку из «Вне занятий». Она не увеличивает прогресс курса. В поиске и последовательности уроков нет титула «О нашей книге». Первый урок — PDF 3, последний — PDF 142.
2. PDF 8, первый шаг: нажать оба стула, окна и рамки. Нужно шесть отмеченных предметов; нажатие по фону не добавляет предмет.
3. Во всех заданиях с палочками перетаскивать палочки из лотка, пробовать бросить мимо образца, поворот, отмену, восстановление после перезагрузки. Проверить углы, треугольники, квадрат, дом, несколько фигур и звезду.
4. В рисовании доступны только чёрный, красный и синий. Правильный рисунок сохраняется после перезагрузки. Замкнутый контур разрешено начинать с любой точки и обводить в обе стороны.
5. Прописи 0–9 и 10 сверить с [наложением на сканы](handwritten-digit-overlay.png): наклон длинной палочки «1», петля и волнистый низ «2», завитки «3», открытая «4», хвосты «5/6/9», перекладина «7», единый штрих «8», наклон «0» и расстояние между цифрами «10».
6. Вместо счётов в заданиях отображаются карточки с жетонами. В оригинальной странице PDF счёты остаются частью старого учебника.
