# Арифметика, 1 класс — постраничное ТЗ для Expo

Подробный разбор предоставленного учебника А. С. Пчёлко и Г. Б. Поляка, издание 1959 года: **144 отдельных Markdown-документа, все печатные задания № 1–892 и 488 извлечённых PNG-фрагментов**. Условия, рисунки, ответы, открытые задания и предложения по интерактивности описаны по страницам. Имена файлов — английские, тексты — русские.

[Исходный PDF](../Matematyka_Pchelko_1klas_1959_skachat.pdf).

- [Все 144 страницы](PAGE_INDEX.md) — указатель с темами, номерами заданий и ссылками на каждый MD.
- [Реестр изображений](ASSET_INDEX.md) — ссылки, размеры, координаты и описания 488 вырезок.
- [Требования к интерактивным заданиям](INTERACTION_SPEC.md) — действия, состояния, проверка, открытые ответы, измерения и доступность.
- [Передача в Expo](EXPO_HANDOFF.md) — учёт обнаруженного прототипа, контракт данных, этапы и критерии приёмки.

## Файлы

| Путь | Назначение |
|---|---|
| `page_docs/arithmetic_grade1_pchelko_1959_p001.md` … `p144.md` | Отдельное описание каждой PDF-страницы |
| `images/pNNN_english_description.png` | Извлечённые иллюстрации, счётные схемы, цифры, прописи, таблицы |
| `pages/page_NNN.png` | Полные сканы страниц для сверки |
| [data/pages.json](data/pages.json) | Постраничный навигационный реестр |
| [data/exercises.json](data/exercises.json) | Номер задания → страницы и документы; продолжения |
| [data/assets.json](data/assets.json) | Изображения, точные координаты вырезки, размеры, SHA-256 |
| [data/quality.json](data/quality.json) | Результат технической проверки комплекта |
| `scripts/` | Скрипты построения указателей и проверки |
| `_work/` | Рабочие OCR, координатные сетки и контактные листы; не источник для генерации приложения |

Пример: [страница 17](page_docs/arithmetic_grade1_pchelko_1959_p017.md), [её скан](pages/page_017.png), [морковки](images/p017_carrots.png). Номер p017 — страница PDF; номер печатного задания хранится отдельно.

Картинки — реальные вырезки из скана с бумажным фоном. Они ещё не содержат полигонов отдельных предметов, прозрачных спрайтов, анимаций или векторных траекторий письма. Требования к этим ресурсам изложены в общем ТЗ. Сомнительные детали скана и открытые результаты не заменены выдуманными строгими ответами.

## Как передавать комплект

Передавайте папку `textbook` целиком: относительные ссылки между MD, изображениями и сканами сохранятся. Для разработки конкретного урока нужны общие требования и соответствующие MD, а не только обзор. Полностью нормализованный исполняемый JSON-банк вопросов создаётся на этапе реализации; текущие JSON — реестры и данные происхождения ресурсов.

Техническую проверку можно повторить из корня проекта:

```sh
python3 textbook/scripts/validate_package.py
```

После изменения описаний или состава изображений сначала обновите указатели:

```sh
python3 textbook/scripts/audit_assets.py
python3 textbook/scripts/build_catalog.py
python3 textbook/scripts/validate_package.py
```

Для аудита вырезок требуются Pillow и OpenCV, для чтения PDF при проверке — PyMuPDF. `complete_pages.py` — рабочий генератор первоначального дополнения 49 отсутствовавших страниц, использует прежние материалы соседнего проекта и перезаписывает эти MD; для обычной проверки его запускать не нужно. Итоговые документы самодостаточны и не зависят от соседнего проекта.
