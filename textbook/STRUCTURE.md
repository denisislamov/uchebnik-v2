# Структура учебника и требования к переносу

**А. С. Пчёлко, Г. Б. Поляк. «Арифметика. Учебник для первого класса начальной школы». Издание пятое. Москва, Учпедгиз, 1959.** Источник — предоставленный PDF `Matematyka_Pchelko_1klas_1959_skachat.pdf`, 144 страницы. Название файла не используется как язык содержания: книга на русском.

Комплект охватывает каждую PDF-страницу, включая обложку, титул, оглавление и выходные данные. На учебных страницах — нумерованные задания № 1–892, ненумерованные вопросы, объяснения, образцы записи, правила, рисунки и прописи. 892 — количество печатных номеров, а не количество отдельных действий ученика: под одним номером могут находиться несколько задач и целые таблицы примеров.

[Полный постраничный указатель](PAGE_INDEX.md) содержит 144 ссылки, темы, номера заданий и количество извлечённых изображений. Конкретные условия и ключи находятся в документах страниц; этот общий документ объясняет устройство курса и правила использования всего пакета.

## 1. Нумерация и идентичность

Файлы страниц: `page_docs/arithmetic_grade1_pchelko_1959_pNNN.md`, где NNN — номер PDF-страницы от 001 до 144. Английское имя стабильно, содержание по-русски. Например, p017 — семнадцатая страница PDF и печатная страница 17. У обложки, титула и выходных данных печатный номер отсутствует; в реестре для них `printedPage = null`.

Не пересчитывать страницы с нуля и не смещать нумерацию на две служебные страницы. Печатные задания начинаются на с. 30. На с. 3–29 много самостоятельных заданий без номеров; они обязательны к переносу наравне с нумерованными.

## 3. Как построено обучение

Курс движется от жизненной сцены и предмета к счётной модели, цифре и абстрактному выражению. Число показывается несколькими способами: предметные группы, косточки счётов, кружки/квадраты, точки домино, монеты, печатный знак и рукописный образец. Эти представления не взаимозаменяемые украшения: они связывают количество, структуру группы, название и запись.

Сложение вводится через добавление и объединение, вычитание — через уход/удаление и оставшееся количество. Рядом могут стоять пара прямой и обратной задачи, перестановка слагаемых, разложение на удобные части. Зачёркнутые предметы нужны для рассуждения об исходном и оставшемся количестве; их нельзя удалить из условия заранее.

Во втором десятке появляются пучок-десяток и отдельные единицы, затем преобразования через 10. Словесные сравнения «на несколько больше/меньше» отрабатываются в разных сюжетах. Двухшаговые задачи учат различать промежуточный результат и окончательный вопрос.

Умножение вводится через одинаковые группы и повторное сложение; деление — через равные части и связь с умножением. Текстовые задачи о цене, массе, длине и объёме перемежаются с чистыми вычислениями. В первой сотне уже знакомые действия переносятся на круглые десятки. Полную таблицу умножения до 100 книга не требует: её основная таблица ограничена произведениями до 20.

Повторение — самостоятельная часть курса, а не список необязательных дубликатов. Составление задачи, формулировка вопроса и дополнение данных проверяют понимание отношений, а не только вычислительный навык.

## 4. Типы исходных задач

| Семейство | Варианты, которые нужно различать |
|---|---|
| Наблюдение и счёт | Все предметы; отдельные цветовые/пространственные группы; порядковый счёт; столько же предметов |
| Сравнение | Величина/длина/высота; количество; на сколько больше/меньше; изменение заданного числа |
| Запись и чтение | Цифра; составное число; последовательность; пропуски; десятки/единицы |
| Вычисление | Один пример; несколько столбиков; цепочка действий; общий оператор у таблицы/рамки/круга |
| Предметная модель | Выложить; передвинуть; убрать; разбить; раздать; собрать десяток; разложить через 10 |
| Текстовая задача | Одно действие; два действия; несколько отдельных вопросов; пара связанных сюжетов |
| Открытая постановка | Придумать условие; придумать вопрос; дополнить число; составить аналогичную задачу |
| Выбор выражения | Найти пример с ответом; упорядочить по результатам; собрать примеры с заданным ответом |
| Графика и геометрия | Пропись; узор; заданное число фигур; клетки; конструкции из палочек |
| Практические величины | Измерить в окружающей среде; взвесить; перелить; начертить заданную длину; вычислить по условию |
| Деньги | Стоимость одного предмета; стоимость набора; сдача; размен монет; цена всей группы под скобкой |
| Игра | Угадать скрытое количество/число; карточки; броски в мишень и подсчёт очков |
| Справочный материал | Решённые образцы; таблицы; сокращения единиц; оглавление и сведения о книге |

Механика, данные, состояния, проверки и варианты доступного управления описаны в [INTERACTION_SPEC.md](INTERACTION_SPEC.md). Привязки к существующим типам прототипа — в [EXPO_HANDOFF.md](EXPO_HANDOFF.md).

## 5. Изображения и визуальный язык

Извлечены 488 PNG-фрагментов: сюжетные сцены, предметные группы, монеты, домино, счёты, цифры, образцы письма, геометрические построения, таблицы, рамки, схемы и правила. Большая часть начала книги цветная; последующая часть преимущественно чёрно-белая штриховая. Полные PNG всех страниц сохранены отдельно.

Сюжетная картинка хранится целиком, а самостоятельные изображения и варианты счётных схем — отдельными файлами. Иногда сохранены и общая группа, и её детали: число PNG поэтому не равно числу уникальных сюжетов. Обычный набранный текст и столбики примеров описаны текстом; простые типографские линейки и номера страниц отражены в композиции/служебных элементах, а не превращены в отдельные спрайты.

Иллюстрацию можно использовать как оригинальную картинку, фон с интерактивными зонами или образец для новой векторной модели. При перерисовке сохранять количество, группировку, относительное положение, зачёркивания, цены, единицы и учебную функцию. Не подменять извлечённый оригинал сгенерированной картинкой. Новые варианты маркировать как адаптацию.

[assets.json](data/assets.json) фиксирует происхождение каждого фрагмента. Все пути относительные, поэтому папку `textbook` можно переносить целиком. Источник для повторной вырезки — соответствующий PNG, а для большего разрешения — PDF.

## 6. Связи и исключения

| Связь / особенность | Требование |
|---|---|
| № 331: с. 74 → 75 | Одна игра; условие начинается на предыдущей странице |
| № 489: с. 92 → 93 | Одна серия примеров, последний `7+7−13` на новой странице |
| № 887: с. 141 → 142 | Две части: умножение с ответом 20; деление с ответом 5 |
| № 581 на с. 107 | Ссылка на задачу 580 с. 106; показать контекст предыдущей задачи |
| Многоточие между сюжетами | Может отделять вторую задачу под тем же номером; не отбрасывать её |
| Многоточие вместо числа | Данное выбирает ученик; это не ошибка OCR и не пустой ответ на вычисление |
| Готовое равенство в образце | Не скрывать автоматически как самостоятельный тест |
| Рукописная цифра/отметка владельца | Описать как след на скане; не использовать как печатное условие |
| С. 5, перекрывающиеся мешки | Строгая оценка количества требует подтверждённой объектной разметки |
| С. 93 и 129, измерения | Отделить реальные результаты от модели; не выводить физические величины из пикселей |
| Служебные знаки с. 3 и 144 | Есть отмеченная неопределённость мелкого типографского чтения, на математику не влияет |

## 7. Формат использования как ТЗ и как промпта

Для человека: начать с этого документа, затем открыть нужную страницу через указатель, прочитать условие/рисунки/ответы и общие правила механики. Для реализации прочитать передачу в Expo и выполнять приёмку по каждому блоку.

Для модели: дать [IMPLEMENTATION_PROMPT.md](IMPLEMENTATION_PROMPT.md), общие правила, конкретные MD выбранного диапазона и доступ к изображениям. Не передавать только этот обзор: в нём намеренно не дублируются тысячи чисел и все условия. Не просить модель восстанавливать недостающую страницу по соседним — файл для каждой страницы уже существует.

Предлагаемые интерактивные тексты, подсказки и сценарии в документах — авторская адаптация для приложения. Тексты издания, интерпретация рисунка и новые условия должны храниться раздельно. Неопределённости и границы автоматической проверки перечислены в [QUALITY_REPORT.md](QUALITY_REPORT.md).
