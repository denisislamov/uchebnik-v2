# Проверка комплекта

Дата подготовки: 8–9 сентября 2026. Источник: предоставленный PDF «Matematyka_Pchelko_1klas_1959_skachat.pdf». Результат — документация и изображения для последующей реализации, а не готовое Expo-приложение.

## Покрытие

- PDF содержит 144 страницы; для каждой есть отдельный MD и полный PNG.
- В существовавших материалах было 95 документов; добавлены 49 отсутствовавших, сохранено и проверено ранее подготовленное содержание.
- По документам найдены все печатные номера 1–892, без разрывов. № 331, 489 и 887 находятся на двух страницах; это продолжения, а не лишние дубликаты. Ненумерованные вопросы, модели, прописи и служебные страницы также описаны.
- В папке изображений 488 PNG-фрагментов; из них 103 добавлены при дополнении отсутствовавших страниц. Есть 17 контактных листов для просмотра вырезок.
- Все страницы просмотрены визуально; все 488 вырезок просмотрены на контактных листах. Для каждой вырезки пиксели точно совпадают с соответствующей областью сохранённого PNG страницы. Координаты, размеры и хеши записаны в `data/assets.json`.
- Дополнительно выполнена вычислительная проверка числовых равенств в Markdown. Проверяется арифметика распознанных выражений, а не автоматически весь смысл текстовой задачи. Повторные появления одного ответа в описании/таблицах входят в число проверок.

Точные текущие количества ссылок, проверенных равенств и результат автоматических проверок — в [data/quality.json](data/quality.json). Скрипт [validate_package.py](scripts/validate_package.py) воспроизводит структурные проверки. Он не заменяет визуальное чтение и не доказывает правильность любого свободного текста.

## Отмеченные неопределённости и границы

| Место | Что известно | Как использовать |
|---|---|---|
| С. 5, ряд мешков | Мешки перекрываются; точные контуры каждого предмета трудно различить даже на увеличенном фрагменте | Сохранить сцену и вопрос. Не включать жёсткую автоматическую оценку до подтверждения объектной разметки; дать режим сопоставления/проверки взрослым |
| С. 3, мелкая сигнатура | Цифра 1 с маленьким надстрочным знаком; чтение знака отмечено как неуверенное | Служебный элемент, не условие задачи; исходный скан доступен |
| С. 144, код типографии | В документе прочитано «III 18/97», мелкие знаки допускают неопределённость | Сохранять примечание рядом с транскрипцией; на задания не влияет |
| Мелкие фоновые надписи на предметах | Некоторые надписи/даты имеют ограниченную читаемость; существенные номиналы и цены описаны | Не делать из фоновой надписи новый тест; при точном восстановлении использовать скан |
| Реальные измерения | Размер комнаты/тетради, объём конкретного стакана и результат действий ребёнка неизвестны заранее | Самооценка/проверка взрослым либо отдельно заданная цифровая модель |
| Открытые задания | Возможны несколько условий, вопросов, наборов монет и выражений | Проверять математическое ограничение/рубрику, не один образцовый текст |

Вырезки сохраняют фон, зернистость, следы старения и часть рукописных следов, присутствующих в оригинале. Они не являются очищенными прозрачными спрайтами. Прямоугольные координаты вырезки не являются масками счётных объектов. Дополнительная разметка, векторные прописи и анимации относятся к этапу разработки.

Проверка полноты нумерации означает наличие описания каждого номера, а не независимую педагогическую рецензию каждой формулировки. Перед выпуском интерактивной версии нужна приёмка каждого перенесённого блока по скану и правилам из [EXPO_HANDOFF.md](EXPO_HANDOFF.md). В текущей работе приложение не собиралось, не публиковалось и не тестировалось на устройствах.
