- **Тип страницы:** упражнения / введение темы / задачи

- **Количество изображений:** 1

## 1. Общее описание

Верхняя треть — два блока примеров 635 и 636 (по 12 примеров): первые столбики вида «a×b:2» (произведение делится на 2), вторые — «a:2+b», третьи — «a×b−c». Далее подзаголовок «Деление на 3 равные части.» и введение новой темы по той же схеме, что и деление на 2: 637 — повторение умножения на 3 и суммы одинаковых слагаемых (4+4+4, 6+6+6); 638 — «Разделить поровну между тремя учениками: 3 карандаша 3:3=, … 18 карандашей 18:3=»; рамка с таблицей деления на 3 (3:3 … 18:3); 639 — разложить 12 квадратиков в 3 ряда; 640 — задача про бревно 15 м на 3 части. Внизу слева типографская сигнатура «8*», справа «115».

## 2. Содержимое по порядку (сверху вниз, слева направо)

### Блок 1. Примеры 635
- **Тип блока:** примеры (три столбика по 4)
- **Текст (дословно):**
Столбик 1: «3×4 : 2», «4×4 : 2», «6×3 : 2», «4×5 : 2».
Столбик 2: «10 : 2+6», «16 : 2+9», «6 : 2+8», «8 : 2+9».
Столбик 3: «2×9− 7», «3×6− 5», «2×8−12», «4×5−17».
- **Изображение:** нет
- **Педагогическая функция:** цепочки из двух действий: умножение и деление на 2; деление и сложение; умножение и вычитание.
- **Предлагаемая интерактивная реализация:** ввод ответов (12 полей); для первого столбика можно показывать промежуточный результат (3×4=12, 12:2=6).

### Блок 2. Примеры 636
- **Тип блока:** примеры (три столбика по 4)
- **Текст (дословно):**
Столбик 1: «3×6 : 2», «2×7 : 2», «4×3 : 2», «2×9 : 2».
Столбик 2: «16 : 2+ 8», «12 : 2+ 8», «14 : 2+12», «18 : 2+11».
Столбик 3: «5×4− 7», «2×8− 9», «3×4− 8», «6×3−15».
- **Изображение:** нет
- **Педагогическая функция:** аналогично 635.
- **Предлагаемая интерактивная реализация:** ввод ответов (12 полей).

### Блок 3. Подзаголовок «Деление на 3 равные части.»
- **Тип блока:** заголовок
- **Текст (дословно):** «Деление на 3 равные части.»
- **Педагогическая функция:** новая тема.
- **Предлагаемая интерактивная реализация:** заголовок экрана.

### Блок 4. Примеры 637
- **Тип блока:** примеры (две строки по 4)
- **Текст (дословно):** строка 1: «1×3   3×3   5×3   4+4+4»; строка 2: «2×3   4×3   6×3   6+6+6».
- **Изображение:** нет
- **Педагогическая функция:** повторение умножения на 3 и представления произведения как суммы трёх одинаковых слагаемых — опора для деления на 3.
- **Предлагаемая интерактивная реализация:** ввод ответов: 1×3=3; 3×3=9; 5×3=15; 4+4+4=12; 2×3=6; 4×3=12; 6×3=18; 6+6+6=18.

### Блок 5. Задание 638 — деление поровну между тремя учениками
- **Тип блока:** упражнение (с записью деления)
- **Текст (дословно):** «638. Разделить поровну между тремя учениками:
3 карандаша      3 : 3 =
6 карандашей     6 : 3 =
9 карандашей     9 : 3 =
12 карандашей    12 : 3 =
15 карандашей    15 : 3 =
18 карандашей    18 : 3 =»
- **Изображение:** нет
- **Педагогическая функция:** введение деления на 3 через раздачу трём получателям.
- **Предлагаемая интерактивная реализация:** drag_share на трёх учеников; ввод частного. Ответы: 1, 2, 3, 4, 5, 6.

### Блок 6. Рамка «деление на 3»
- **Тип блока:** таблица / выделенная рамка (запомнить)
- **Текст (дословно):** строка 1: «3 : 3   9 : 3   15 : 3»; строка 2: «6 : 3   12 : 3   18 : 3».
- **Изображение:** [p115_frame_div_by_3.png](../images/p115_frame_div_by_3.png) — прямоугольная рамка, внутри полужирным 6 выражений деления на 3 без ответов (2 строки × 3).
- **Педагогическая функция:** табличные случаи деления на 3 для запоминания.
- **Предлагаемая интерактивная реализация:** флэшкарты / ввод: 3:3=1, 6:3=2, 9:3=3, 12:3=4, 15:3=5, 18:3=6.

### Блок 7. Задание 639 — квадратики
- **Тип блока:** практическое задание
- **Текст (дословно):** «639. Разложите 12 квадратиков в 3 одинаковых ряда. Сколько квадратиков получилось в каждом ряду?»
- **Изображение:** нет
- **Педагогическая функция:** наглядное деление 12 на 3 равные части (раскладка предметов рядами).
- **Предлагаемая интерактивная реализация:** 12 квадратиков перетаскиваются в 3 ряда (сетка с 3 строками); проверка: по 4 в каждом; ввод ответа 4. Решение: 12 : 3 = 4.

### Блок 8. Задача 640
- **Тип блока:** задача
- **Текст (дословно):** «640. Плотники распилили бревно длиной в 15 м на 3 равные части. Какой длины получилась каждая часть?»
- **Изображение:** нет
- **Педагогическая функция:** деление величины (метры) на 3.
- **Предлагаемая интерактивная реализация:** ввод ответа; можно показать отрезок 15 м, который ученик делит двумя метками на равные части. Решение: 15 : 3 = 5 (м). Ответ: 5 м.

### Блок 9. Служебные элементы
- **Тип блока:** служебный
- **Текст:** внизу слева «8*» (типографская сигнатура), внизу справа «115».

## 5. Типы интерактивности, которые нужны на этой странице

- expression_input — 635, 636, 637 (с показом промежуточного результата в цепочках «a×b:2»).
- drag_share — раздача карандашей трём ученикам (638).
- flashcards / number_input — рамка деления на 3.
- drag_drop — раскладка 12 квадратиков в 3 ряда (639).
- word_problem — 640 (можно с визуализацией отрезка 15 м).

## 6. Замечания для реализации

- Цепочки вида «3×4 : 2» решаются слева направо: 3×4=12, 12:2=6. Подсказку о порядке действий давать при ошибке.
- Схема введения деления на 3 повторяет схему деления на 2 (стр. 113–114): повторение умножения → раздача поровну → рамка → задачи. Использовать те же компоненты.
- Задание 639 в книге — с бумажными квадратиками; в приложении — перетаскивание на сетку.
- Сигнатура «8*» — служебный элемент.
- Все фрагменты читаются чётко.
