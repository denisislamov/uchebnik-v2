## 1. Общее описание

Полностью текстовая страница закрепления умножения 4. Задачи 560–563: простая (4×3 — колёса автомобилей), составная 561 (умножение + увеличение на несколько единиц) с дополнительным заданием составить похожую задачу про свой класс, составная 562 (умножение + сложение) и 563 — составить похожую задачу. Далее два столбика примеров: 564 (умножение с вычитанием, 3 столбика по 4) и 565 (чистая таблица умножения 1–4, 4 столбика по 4). Затем задачи на метры материи 566–567 (4×3 и 3×4), примеры 568 (3 столбика по 4) и составная задача 569 (2 платья по 4 м + передник 1 м). Иллюстраций нет. Номер «104» внизу слева.

## 2. Содержимое по порядку (сверху вниз, слева направо)

### Блок 1. Задача 560
- **Тип блока:** задача
- **Текст (дословно):** «560. У автомобиля 4 колеса. Сколько колёс у трёх таких автомобилей?»
- **Педагогическая функция:** умножение 4×3 в бытовой ситуации.
- **Предлагаемая интерактивная реализация:** `word_problem`: 4 × 3 = 12, ответ «12 колёс». Можно показать 3 машины и дать посчитать колёса.

### Блок 2. Задача 561 + составление задачи
- **Тип блока:** задача (2 действия) + составление задачи
- **Текст (дословно):** «561. Володя решил на уроке 3 столбика примеров, по 4 примера в каждом столбике, а Вася успел решить на 2 примера больше. Сколько примеров решил Вася?» Далее с новой строки (без номера): «Составьте задачу, похожую на предыдущую, про свой класс.»
- **Педагогическая функция:** умножение, затем «на несколько единиц больше»; перенос структуры задачи на свой опыт.
- **Предлагаемая интерактивная реализация:** `word_problem` в два шага: 1) 4 × 3 = 12 (примеров решил Володя); 2) 12 + 2 = 14 (примеров решил Вася). Ответ «14 примеров». Затем `compose_problem`: открытый ответ; критерии: структура «a столбиков по b … , а другой на c больше», числа в пределах таблицы (произведение ≤ 20, сумма ≤ 20).

### Блок 3. Задача 562
- **Тип блока:** задача (2 действия)
- **Текст (дословно):** «562. В живом уголке в трёх банках по 4 рыбки в каждой и в аквариуме 6 рыбок. Сколько всего рыбок в живом уголке?»
- **Предлагаемая интерактивная реализация:** `word_problem` в два шага: 1) 4 × 3 = 12; 2) 12 + 6 = 18. Ответ «18 рыбок».

### Блок 4. Задание 563
- **Тип блока:** составление задачи
- **Текст (дословно):** «563. Составьте задачу, похожую на предыдущую.»
- **Предлагаемая интерактивная реализация:** `compose_problem`: открытый ответ; критерии: структура «n групп по k + ещё m» с ответом ≤ 20; проверка решения ученика по его же числам.

## 6. Замечания для реализации

- Примеры 564 содержат случаи с ответом 0 (3×3−9, 3×5−15) — убедиться, что ввод «0» принимается.
- В 565 пример «4×4» повторяется дважды — это не ошибка распознавания, так в книге.
- Задача 567: порядок множителей «3 м × 4 пальто» — в книге принято записывать «3×4» (по 3 взять 4 раза); при проверке принимать также 4×3.
- Единица «м» (метр) набрана курсивом — в приложении показывать как «м».
- Задачи на составление (при 561, 563) — открытые; для проверки нужен конструктор задач или свободный ввод с ручной/эвристической проверкой чисел.
- Номер 564 в OCR ошибочно распознан как 565 — на странице чётко «564.» и «565.».
- Неразборчивых мест нет.
