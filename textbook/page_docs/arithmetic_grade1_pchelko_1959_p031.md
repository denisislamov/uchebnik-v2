## Иллюстрация с птичками

Под примерами — **две картинки с птицами на ветке/проводе:**

- **Слева** — на веточке сидят **шесть синичек** (жёлто-серые птички), а справа от них **одна птичка подлетает** (в полёте) — иллюстрация к задаче 10.
- **Справа** — на **проводе сидят шесть ласточек** (тёмные с рыжим горлом), а **одна ласточка улетает** (в полёте справа) — иллюстрация к задаче 11.

## Задание «Считайте по 2» (яблоки и домино)

> **Считайте по 2:**

- Нарисован ряд из **пяти веточек с двумя яблоками** на каждой (жёлто-красные яблоки парами) — счёт двойками.
- Под ними — **четыре костяшки домино**, показывающие чётные числа: **2+2, 4+2, 6+2, 8+2** (кружки в два ряда, добавляются по два).

Под костяшками — равенства-«лесенка»:

> **2 + 2 = / 2 + 1 + 1**
> **4 + 2 = / 4 + 1 + 1**
> **6 + 2 = / 6 + 1 + 1**
> **8 + 2 = / 8 + 1 + 1**

Внизу — числовой ряд чётных чисел: **2 4 6 8 10**.

## 5. Интерактивная реализация

Использовать [общие контракты заданий](../INTERACTION_SPEC.md). Для каждого отдельно проверяемого вопроса/примера назначить стабильный ID `p031-exNNN-partNN`; для ненумерованных — `p031-blockNN-partNN`. Числовые ответы вводятся независимо (`number_input`); набор примеров не сводится к одному полю. Текстовые задачи используют `word_problem`, открытое составление — `problem_builder`, счёт предметов — `counting_tap`, разбиение — `group_partition`, таблицы — `table_fill`, рисунок — `draw_canvas`, прописи — `digit_tracing`, палочки — `drag_drop_sticks`. Применять только типы, соответствующие фактическим блокам этой страницы.
