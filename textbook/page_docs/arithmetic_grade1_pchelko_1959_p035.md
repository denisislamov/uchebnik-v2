## Наглядные костяшки домино (прибавить 3)

- Верхняя костяшка (одна): показывает **1 + 3** — рядом равенства-«лесенка»:
  > **1 + 3 = / 1 + 1 + 1 + 1 / 1 + 1 + 2**
- Ниже — **три костяшки домино** в ряд для примеров **2 + 3, 3 + 3, 4 + 3**, под каждой равенства-«лесенка»:
  > **2 + 3 = / 2 + 1 + 1 + 1 / 2 + 2 + 1**
  > **3 + 3 = / 3 + 1 + 1 + 1 / 3 + 2 + 1**
  > **4 + 3 = / 4 + 1 + 1 + 1 / 4 + 2 + 1**

## 3. Ответы и требования к интерактивным заданиям

№35: четыре разных выражения a−2, a=3…10; верное значение каждого. №37а:7+1=8 камешков; №37б:8−2=6 камешков; многоточие перед второй задачей сохранить как печатное разделение, это не утраченный текст. №39: 3=1+2=2+1=1+1+1. №41: 1+3=4 ямы. На схемах диагональ разделяет группы, не зачёркивает их.

## 5. Интерактивная реализация

Использовать [общие контракты заданий](../INTERACTION_SPEC.md). Для каждого отдельно проверяемого вопроса/примера назначить стабильный ID `p035-exNNN-partNN`; для ненумерованных — `p035-blockNN-partNN`. Числовые ответы вводятся независимо (`number_input`); набор примеров не сводится к одному полю. Текстовые задачи используют `word_problem`, открытое составление — `problem_builder`, счёт предметов — `counting_tap`, разбиение — `group_partition`, таблицы — `table_fill`, рисунок — `draw_canvas`, прописи — `digit_tracing`, палочки — `drag_drop_sticks`.
