## 1. Общее описание

Страница без иллюстраций, продолжает тему «Прибавить и отнять 5» (домино — на стр. 43). Вверху пять записей «дробью»: «1+5= / 1+2+3», «2+5= / 2+3+2», «3+5= / 3+3+2» (в ряд) и «4+5= / 4+2+3», «5+5= / 5+2+3» (второй ряд, по центру) — приём прибавления 5 по частям. Далее три задачи (№ 101 флаги 1+5, № 102 картины 5+5 с самостоятельной постановкой вопроса, № 103 составить задачу 3+5), столбик № 104 (сложение с 5 с перестановкой слагаемых), задание с разрезной таблицей № 105, столбик № 106 (сложение с 5 и повторение −2, −3, −4). Внизу практическое задание № 107 с кружками в коробке (1+5, затем 6−5), пары № 108 (1+5/6−5 … 5+5/10−5) и четыре записи вычитания 5 по частям: «6−5= / 6−3−2», «7−5= / 7−2−3», «8−5= / 8−2−3», «9−5= / 9−3−2».

## 2. Содержимое по порядку (сверху вниз, слева направо)

### Блок 1. Записи прибавления 5 по частям
- **Тип блока:** схема-запись (5 штук)
- **Текст (дословно):**
  ```
  1+5=      2+5=      3+5=
  1+2+3     2+3+2     3+3+2

       4+5=      5+5=
       4+2+3     5+2+3
  ```
  (каждая запись: верхняя строка с пустым местом для ответа, черта, нижняя строка — разложение)
- **Изображение:** нет
- **Педагогическая функция:** прибавить 5 = прибавить 2 и 3 (или 3 и 2): 1+5=6, 2+5=7, 3+5=8, 4+5=9, 5+5=10. Соотносится с домино стр. 43.
- **Предлагаемая интерактивная реализация:** number_input в верхнюю строку; step_addition: анимация с промежуточным результатом (например 1+2=3, 3+3=6). Можно показать домино с предыдущей страницы как подсказку.

### Блок 2. Задача № 101
- **Тип блока:** задача
- **Текст (дословно):** «101. К празднику на школьном здании вывесили 1 большой флаг и 5 флагов поменьше. Сколько всего флагов вывесили на школьном здании?»
- **Изображение:** нет
- **Педагогическая функция:** 1 + 5 = 6.
- **Предлагаемая интерактивная реализация:** word_problem; ответ 6.

### Блок 3. Задача № 102
- **Тип блока:** задача (поставить вопрос)
- **Текст (дословно):** «102. В школьном зале повесили 5 картин на одной стене и столько же на другой.
  Поставить вопрос и решить задачу.»
- **Изображение:** нет
- **Педагогическая функция:** ученик формулирует вопрос («Сколько всего картин повесили?») и решает 5 + 5 = 10; «столько же» (здесь не выделено жирным).
- **Предлагаемая интерактивная реализация:** pose_question (выбор правильного вопроса) + number_input → 10.

### Блок 4. Задача № 103
- **Тип блока:** задача (составить задачу)
- **Текст (дословно):** «103. Составьте задачу, в которой нужно к 3 прибавить 5.»
- **Изображение:** нет
- **Педагогическая функция:** 3 + 5 = 8.
- **Предлагаемая интерактивная реализация:** compose_problem; ответ 8.

- **Тип блока:** инструкция (разрезная таблица)

- **Предлагаемая интерактивная реализация:** number_input.

### Блок 8. Задание № 107 (две части)
- **Тип блока:** практическое задание (кружки, коробка)
- **Текст (дословно):** «107. Положите в пустую коробку 1 кружок и 5 кружков. Сколько всего кружков стало в коробке?
  … Выньте из коробки 5 кружков. Сколько кружков осталось в коробке?»
- **Изображение:** нет
- **Педагогическая функция:** предметная связь сложения и вычитания: 1 + 5 = 6, 6 − 5 = 1.
- **Предлагаемая интерактивная реализация:** drag_drop: пустая коробка; ученик кладёт 1 кружок, затем 5; вводит 6; затем вынимает 5; вводит 1.

### Блок 9. Примеры № 108
- **Тип блока:** примеры (5 пар)
- **Текст (дословно):**
  ```
  108. 1+5   2+5   3+5   4+5   5+5
       6−5   7−5   8−5   9−5   10−5
  ```
- **Изображение:** нет
- **Педагогическая функция:** связь сложения и вычитания 5.
- **Предлагаемая интерактивная реализация:** number_input парами.

### Блок 10. Записи вычитания 5 по частям
- **Тип блока:** схема-запись (4 штуки, в ряд)
- **Текст (дословно):**
  ```
  6−5=      7−5=      8−5=      9−5=
  6−3−2     7−2−3     8−2−3     9−3−2
  ```
- **Изображение:** нет
- **Педагогическая функция:** вычитание 5 по частям: 6−5=1, 7−5=2, 8−5=3, 9−5=4. Обратите внимание: порядок частей чередуется (3 и 2 / 2 и 3).
- **Предлагаемая интерактивная реализация:** number_input + step_subtraction с промежуточными результатами (6−3=3, 3−2=1 и т. д.).
