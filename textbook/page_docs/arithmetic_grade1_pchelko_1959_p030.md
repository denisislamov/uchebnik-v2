## 3. Ответы и требования к интерактивным заданиям

№2: 6+1=7 горшков. №3: 9+1=10 листьев. №6: 7−1=6 учебных дней — историческое условие, не менять на современное расписание. №7: 10−1=9 горшков. Ряд ёлок содержит 10 деревьев; ряд чисел 1…10 соответствует счёту.

## 5. Интерактивная реализация

Использовать [общие контракты заданий](../INTERACTION_SPEC.md). Для каждого отдельно проверяемого вопроса/примера назначить стабильный ID `p030-exNNN-partNN`; для ненумерованных — `p030-blockNN-partNN`. Числовые ответы вводятся независимо (`number_input`); набор примеров не сводится к одному полю. Текстовые задачи используют `word_problem`, открытое составление — `problem_builder`, счёт предметов — `counting_tap`, разбиение — `group_partition`, таблицы — `table_fill`, рисунок — `draw_canvas`, прописи — `digit_tracing`, палочки — `drag_drop_sticks`. Применять только типы, соответствующие фактическим блокам этой страницы.

## 6. Замечания для реализации

- Дословное условие находится в разделе 2. Решения и сценарии взаимодействия в разделе 3 — редакторское дополнение для приложения, не текст книги.
- Готовые равенства-образцы не скрывать автоматически. Ответы ученика сохранять отдельно от источника.
- Свободный рисунок и устный рассказ не оценивать сравнением пикселей или совпадением одной фразы.
