## 1. Общее описание

Страница открывает подтему «Прибавить и отнять 4» (заголовок жирным по центру вверху). Сначала вопрос о составе числа 4 (№ 72), затем столбики примеров на сложение трёх чисел (№ 73), где 4 «спрятано» как 2+2, 1+3, 3+1. Задание № 74 (кружки 2 слева и 4 справа) вводит наглядную модель: далее два ряда по три костяшки домино, на каждой слева число (2, 4, 6 / 1, 3, 5), справа всегда 4 точки; под каждой костяшкой запись «N+4=» с чертой и под ней разложение «N+2+2». Ниже три текстовые задачи (№ 75 палочки 6+4, № 76 перочистка 3+4, № 77 составить задачу 5+4) и столбик № 78 на сложение с 4. Педагогическая идея: 4 прибавляют по частям — сначала 2, потом ещё 2.

## 6. Замечания для реализации

- Порядок домино в книге: верхний ряд 2+4, 4+4, 6+4 (чётные), нижний ряд 1+4, 3+4, 5+4 (нечётные). Сохранить.
- Записи под домино — «дробью»: «N+4=» над чертой, «N+2+2» под ней. Верхнюю строку делать полем ввода, нижнюю — подсказкой.
- Слово «перочистка» (№ 76) устарело — добавить всплывающее пояснение с картинкой.
- В № 73 у OCR всё верно; в № 78 четвёртая колонка «4+3 / 3+4 / 6+4 / 5+4» сверена по скану.
- Неразборчивых фрагментов нет.
