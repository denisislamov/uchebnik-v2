- **Тема страницы:** Вычитание 3 из чисел 4–10 по частям (−1−1−1 и −2−1) с опорой на схемы с зачёркнутыми кружками; связь сложения и вычитания (1+3 / 4−3)

## 1. Общее описание

Страница вводит вычитание числа 3. Композиция: вверху одна схема-рамка с 4 кружками (3 зачёркнуты) и рядом запись «4−3= / 4−1−1−1 / 4−2−1»; ниже — ряд из трёх таких же рамок для 5−3, 6−3, 7−3, под каждой — такая же тройная запись. Потом пары примеров № 58 (1+3 / 4−3 …), задача № 59 про тарелки, столбик № 60. Во второй половине страницы — ещё три рамки для 8−3, 9−3, 10−3 с записями, пары № 61 (5+3 / 8−3 …) и столбик № 62. Ключевая идея: вычитание 3 выполняется по частям — либо по единице (−1−1−1), либо сначала 2, потом 1 (−2−1); наглядно это показано зачёркнутыми кружками в рамке. Каждый пример на вычитание сопоставляется с обратным примером на сложение.

## 2. Содержимое по порядку (сверху вниз, слева направо)

### Блок 1. Схема 4 − 3
- **Тип блока:** счётная схема + запись
- **Текст (дословно):** справа от рамки: «4−3=» (с чертой под ней), ниже «4−1−1−1», ниже «4−2−1».
- **Изображение:** [p038_circles_4_minus_3.png](../images/p038_circles_4_minus_3.png) — прямоугольная рамка, внутри 4 кружка в две строки по 2: верхняя строка — 1 пустой кружок и 1 зачёркнутый косой чертой; нижняя строка — 2 зачёркнутых. Итого 4 кружка, 3 зачёркнуты, 1 остался. Чёрно-белая графика.
- **Педагогическая функция:** первая наглядная модель вычитания 3: из 4 кружков убрали (зачеркнули) 3, остался 1. Записи показывают два способа: по единице и «2 и 1». Ответ 4 − 3 = 1.
- **Предлагаемая интерактивная реализация:** ученик по нажатию «зачёркивает» 3 кружка (counting_tap с зачёркиванием), затем вводит ответ в пустое поле «4−3=». Дополнительно: пошаговая анимация «4−1−1−1» (по одному кружку) и «4−2−1» (сразу два, потом один) с промежуточными числами 3, 2, 1 / 2, 1.

## 5. Типы интерактивности, которые нужны на этой странице

- counting_tap с режимом «зачеркнуть» — ученик зачёркивает заданное число кружков в рамке.
- step_subtraction (новый тип): анимированное вычитание по частям (−1−1−1 и −2−1) с показом промежуточных чисел.
- number_input — ввод ответов в пустые поля «N−3=» и в столбиках примеров.
- word_problem — задача № 59.
- read_aloud.

## 6. Замечания для реализации

- В книге под каждой схемой запись имеет вид «дроби»: сверху «N−3=» с пустым местом для ответа, под чертой два способа разложения. В приложении показывать поле ввода в верхней строке, а строки «−1−1−1» и «−2−1» — как подсказки-анимации.
- Кружки в рамках 8, 9, 10 сгруппированы по два (с промежутками) — это помогает считать; сохранить группировку при отрисовке.
- Зачёркнутые кружки — «убранные»: важно, чтобы ученик считал именно незачёркнутые.
- Все схемы верхнего ряда (4–7) и нижнего (8–10) идут последовательно; желательно проходить их по порядку.
- Неразборчивых фрагментов нет; OCR ошибочно распознал «−» как «-» и «Ю» вместо «10» — сверено по скану.
