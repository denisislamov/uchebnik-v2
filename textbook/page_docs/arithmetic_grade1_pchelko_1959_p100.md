## 1. Общее описание

Продолжение схем умножения 3 со стр. 99. В верхней половине — три ряда групп кружков (по 3 кружка треугольником): 4, 5 и 6 групп, под ними суммы «3 + 3 + 3 + 3 =» и т. д. с подчёркиванием (первые три тройки — одна черта, остальные — другая: опора на 3×3 = 9), справа жирные примеры «3×4=», «3×5=», «3×6=». Далее рамка-таблица умножения 3: «3×2 3×3 3×4 3×5 3×6» в одну строку. Ниже задача 536 про треугольники из палочек (3×6) и три задачи 537–539 на умножение единицы (1×5, 1×4, 1×3) — особый случай «по 1». Внизу сводные примеры 540: пять столбиков, в каждом 1×n, 2×n, 3×n для n = 2…6. Номер страницы «100» внизу слева.

## 2. Содержимое по порядку (сверху вниз, слева направо)

### Блок 1. Схема «4 тройки кружков → 3 + 3 + 3 + 3 = → 3×4=»
- **Тип блока:** счётная схема + примеры
- **Текст (дословно):** «3 + 3 + 3 + 3 =» (первые три слагаемых подчёркнуты одной чертой, четвёртая «3» — короткой отдельной чертой) и «3×4=» (жирным, справа)
- **Изображение:** [p100_circles_3x4.png](../images/p100_circles_3x4.png) — четыре группы по 3 пустых кружка (1 сверху, 2 снизу), всего 12 кружков, в ряд.
- **Педагогическая функция:** 3×4 = 9 + 3 = 12.
- **Предлагаемая интерактивная реализация:** `counting_tap` + `sum_to_product`, подсветка «3 группы = 9» + «ещё 3». Ответы 12 и 12.

### Блок 2. Схема «5 троек → 3 + 3 + 3 + 3 + 3 = → 3×5=»
- **Тип блока:** счётная схема + примеры
- **Текст (дословно):** «3 + 3 + 3 + 3 + 3 =» (подчёркнуты первые три тройки и отдельно «3 + 3») и «3×5=»
- **Изображение:** [p100_circles_3x5.png](../images/p100_circles_3x5.png) — пять групп по 3 кружка, всего 15.
- **Педагогическая функция:** 3×5 = 9 + 6 = 15.
- **Предлагаемая интерактивная реализация:** как блок 1. Ответы 15 и 15.

### Блок 5. Задача 536 (палочки)
- **Тип блока:** задача / практическое задание
- **Текст (дословно):** «536. Из трёх палочек составить треугольник. Составить 6 таких треугольников. Сколько пошло палочек на 6 треугольников?»
- **Педагогическая функция:** предметная модель 3×6: каждый треугольник — 3 палочки.
- **Предлагаемая интерактивная реализация:** `drag_drop_sticks`: ученик перетаскивает палочки, собирая треугольник, затем — 6 треугольников (или нажимает «ещё треугольник» 6 раз со счётчиком палочек); затем вводит ответ: 3 × 6 = 18 палочек.

## 6. Замечания для реализации

- Схемы — продолжение стр. 99 (3×2, 3×3); объединить в одну ленту «3×2 … 3×6».
- Подчёркивания в суммах показывают опору на 3×3 = 9 (три тройки) — воспроизвести подсветкой.
- Задачи 537–539 вводят умножение единицы (1×n = n); в приложении можно дать пояснение «по 1 взять n раз — получится n».
- В задаче 536 формулировка в неопределённой форме («составить») — сохранить дословно; в приложении добавить инструкцию «собери».
- Все числа и ответы проверены; неразборчивых мест нет. (OCR ошибочно распознал «б таких треугольников» — в книге «6».)
