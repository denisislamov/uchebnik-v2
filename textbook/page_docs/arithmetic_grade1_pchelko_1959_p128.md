- **Скан страницы:** [страница 128](../pages/page_128.png)

- **Тема страницы:** Таблица чисел 1–100, пропуски, номера страниц и домов
- **Тип страницы:** учебная; объяснение / упражнения / практические задания (состав блоков ниже).
- **Номера заданий на странице:** 736, 737, 738, 739, 740, 741, 742, 743, 744

## 1. Общее описание и порядок чтения

Материал читается сверху вниз, в пределах ряда слева направо. Тема: Таблица чисел 1–100, пропуски, номера страниц и домов. Порядок блоков и состав иллюстраций приведены ниже. Исходные вопросы, образцы с готовым ответом и задания с пустыми полями должны оставаться разными элементами интерфейса. Печатный номер страницы — 128, внизу слева.

## 3. Ответы и требования к интерактивным заданиям

№736: 30,40,70,90,49. №737: открыть36,40,63,80,92 и вернуться на128; сохранить прогресс поиска. №738: 57,30,40,70,90. №739: первая группа — все10 ячеек5-го столбца, вторая —3-й столбец в строках1,3,5,7,9. №740: 43,48,49. №741: открытое наблюдение, нет общего ответа о конкретной улице; для приложения использовать вымышленную улицу, не требовать домашний адрес. №743: 3 группы по4,4×3=12; сюжет и вопрос проверяет взрослый.

## 5. Интерактивная реализация

Использовать [общие контракты заданий](../INTERACTION_SPEC.md). Для каждого отдельно проверяемого вопроса/примера назначить стабильный ID `p128-exNNN-partNN`; для ненумерованных — `p128-blockNN-partNN`. Числовые ответы вводятся независимо (`number_input`); набор примеров не сводится к одному полю. Текстовые задачи используют `word_problem`, открытое составление — `problem_builder`, счёт предметов — `counting_tap`, разбиение — `group_partition`, таблицы — `table_fill`, рисунок — `draw_canvas`, прописи — `digit_tracing`, палочки — `drag_drop_sticks`. Применять только типы, соответствующие фактическим блокам этой страницы.

## 6. Замечания для реализации

- Дословное условие находится в разделе 2. Решения и сценарии взаимодействия в разделе 3 — редакторское дополнение для приложения, не текст книги.
- Готовые равенства-образцы не скрывать автоматически. Ответы ученика сохранять отдельно от источника.
- Свободный рисунок и устный рассказ не оценивать сравнением пикселей или совпадением одной фразы.
