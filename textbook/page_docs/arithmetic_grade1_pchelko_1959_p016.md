# Арифметика, 1 класс (Пчёлко, Поляк, 1959) — страница 016

- **Скан страницы:** [page_016.png](../pages/page_016.png)
- **Раздел:** Первый десяток → Число 5 (продолжение) → знакомство со знаками «+» и «=», примеры на прибавление 1
- **Тема страницы:** Введение записи сложения: четыре картинки (2 куклы, 3 щенка, 4 козы, 5 котят) с записями 1 + 1 = 2, 2 + 1 = 3, 3 + 1 = 4, 4 + 1 = 5 на карточках; примеры с пустым ответом.
- **Тип страницы:** введение понятия (знаки «+», «=») / упражнения
- **Номера заданий на странице:** без нумерации
- **Количество изображений:** 12

## 1. Общее описание

Страница без единого слова текста — только картинки и записи из карточек. Это первое появление знаков «+» и «=» в учебнике. Страница разбита на две колонки и два ряда картинок. Вверху слева — две куклы на стульчиках (1 + 1 = 2), вверху справа — три щенка (2 + 1 = 3), внизу слева — четыре козы (3 + 1 = 4), внизу справа — пять котят (4 + 1 = 5). Под каждой картинкой запись сложения набрана в рамочках-карточках (как разрезные цифры и знаки, которые дети выкладывают на парте). В самом низу — четыре примера на карточках с пустым местом после «=»: 1 + 1 =, 2 + 1 =, 3 + 1 =, 4 + 1 =, которые ученик должен закончить, положив карточку с ответом. Педагогический смысл: связать наглядную ситуацию «столько-то и ещё один» с математической записью; научить читать запись «один плюс один равно два» (в книге 1959 г. читали «к одному прибавить один, получится два»).

## 5. Типы интерактивности, которые нужны на этой странице

- counting_tap (счёт кукол, щенков, коз, котят с группировкой «n и ещё 1»)
- read_aloud (озвучивание записи сложения по символам — новый навык чтения знаков «+», «=»)
- card_equation (новый тип: составление записи из карточек-цифр и карточек-знаков, как из разрезного материала; перетаскивание карточки ответа в пустое место)
- expression_input / pick_number (ответ на пример)

## 6. Замечания для реализации

- Это первая страница со знаками «+» и «=». Перед выполнением примеров нужно объяснение (озвучка): «плюс» — прибавить, «равно» — получится. В методике 1959 г. записи читались «к одному прибавить один, получится два» — в озвучке можно давать оба варианта.
- Записи оформлены как карточки (разрезные цифры): в приложении уместно сделать «набор карточек», который потом переиспользуется на стр. 17, 19, 21 и далее.
- Порядок картинок задаёт числовой ряд 2, 3, 4, 5 — каждое следующее число получается прибавлением 1.
- Количество животных пересчитано по вырезкам: куклы 2, щенки 3, козы 4, котята 5.
- Текстов на странице нет, неразборчивых фрагментов нет. OCR прочитал только цифры примеров.
