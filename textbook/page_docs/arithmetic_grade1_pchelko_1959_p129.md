## 3. Ответы и требования к интерактивным заданиям

№745: модель20:4=5, распределение20 предметов между4 участниками или на4 части; принимать связный сюжет. №747: выделить интервалы от начала до1,5,9. №748/749:проверять заданные конечные отметки в условной модели метра. №750: по масштабу нарисованной линейки отрезок около4 см (отношение длин≈0,4 от10 см); это оценка по скану, не надёжная физическая калибровка. До подтверждения оригинального масштаба использовать виртуальную модель4 см с явной отметкой редакторского допущения. №751/753:реальные измерения индивидуальны, фиксированного ответа нет. №752: виртуальный отрезок10 единиц-сантиметров или реальное измерение вне экрана. №754: 20 см, разметка равными единицами. №755: 18−4=14 см. №756: 15:3=5 см.

## 5. Интерактивная реализация

Использовать [общие контракты заданий](../INTERACTION_SPEC.md). Для каждого отдельно проверяемого вопроса/примера назначить стабильный ID `p129-exNNN-partNN`; для ненумерованных — `p129-blockNN-partNN`. Числовые ответы вводятся независимо (`number_input`); набор примеров не сводится к одному полю. Текстовые задачи используют `word_problem`, открытое составление — `problem_builder`, счёт предметов — `counting_tap`, разбиение — `group_partition`, таблицы — `table_fill`, рисунок — `draw_canvas`, прописи — `digit_tracing`, палочки — `drag_drop_sticks`. Применять только типы, соответствующие фактическим блокам этой страницы.

## 6. Замечания для реализации

- Дословное условие находится в разделе 2. Решения и сценарии взаимодействия в разделе 3 — редакторское дополнение для приложения, не текст книги.
- Готовые равенства-образцы не скрывать автоматически. Ответы ученика сохранять отдельно от источника.
- Свободный рисунок и устный рассказ не оценивать сравнением пикселей или совпадением одной фразы.
- Экранные пиксели не равны физическим сантиметрам. Не обещать измерение реальных предметов экранной линейкой без калибровки; режим виртуального измерения обозначить явно.
