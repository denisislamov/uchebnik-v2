## 6. Замечания для реализации

- Учебного содержания нет. В приложении можно объединить с обложкой в один экран «О книге» либо показать как второй экран заставки.
- Орфография: «УТВЕРЖДЁН» — с буквой Ё (в книге ё печатается). В OCR имя автора искажено («ПЧЁУ1К0») — правильно «ПЧЁЛКО».
- Разделитель «·» между «МОСКВА» и «1959» — точка по центру строки.
- Весь текст читается уверенно, неразборчивых мест нет.
