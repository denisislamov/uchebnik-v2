## Иллюстрация «считай по 2»: вишни и домино

- Нарисован ряд из **пяти веточек вишни**, на первой — **одна вишня**, на следующих четырёх — по **две вишни** (всего 9) — счёт двойками для **нечётных** чисел.
- Ниже — **четыре костяшки домино**, у каждой **диагональная линия разделяет исходное число и 2 добавляемых кружка**; перечёркнутых кружков нет: показывают **1+2, 3+2, 5+2, 7+2**.

Под костяшками — равенства-«лесенка»:

> **1 + 2 = / 1 + 1 + 1**
> **3 + 2 = / 3 + 1 + 1**
> **5 + 2 = / 5 + 1 + 1**
> **7 + 2 = / 7 + 1 + 1**

Под ними — числовой ряд нечётных чисел: **1 3 5 7 9**.

## Задачи 25 и 26

> **25.** Лида принесла в класс **3 дубовых листа и 2 кленовых.** Сколько всего листьев она принесла?

> **26.** Миша принёс из лесу **5 сосновых шишек и 2 еловых.** Сколько всего шишек принёс Миша?

Между задачами и примером 27 — **две картинки шишек**: слева **сосновая шишка** (с пучком хвои), справа **еловая шишка** (продолговатая).

## 3. Ответы и требования к интерактивным заданиям

№25: 3+2=5 листьев. №26: 5+2=7 шишек. Вишни: 1+2+2+2+2=9, накопительный ряд 1,3,5,7,9. Диагональ в рамках разделяет слагаемые, а не вычёркивает предметы.

## 5. Интерактивная реализация

Использовать [общие контракты заданий](../INTERACTION_SPEC.md). Для каждого отдельно проверяемого вопроса/примера назначить стабильный ID `p033-exNNN-partNN`; для ненумерованных — `p033-blockNN-partNN`. Числовые ответы вводятся независимо (`number_input`); набор примеров не сводится к одному полю. Текстовые задачи используют `word_problem`, открытое составление — `problem_builder`, счёт предметов — `counting_tap`, разбиение — `group_partition`, таблицы — `table_fill`, рисунок — `draw_canvas`, прописи — `digit_tracing`, палочки — `drag_drop_sticks`. Применять только типы, соответствующие фактическим блокам этой страницы.
