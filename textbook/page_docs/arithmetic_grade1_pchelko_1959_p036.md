## Наглядные костяшки домино (прибавить 3)

**Три костяшки домино** в ряд, у каждой кружки разделены линией на слагаемые; зачёркиваний нет — показывают **5+3, 6+3, 7+3**.

Под костяшками — равенства-«лесенка»:

> **5 + 3 = / 5 + 1 + 1 + 1 / 5 + 2 + 1**
> **6 + 3 = / 6 + 1 + 1 + 1 / 6 + 2 + 1**
> **7 + 3 = / 7 + 1 + 1 + 1 / 7 + 2 + 1**

---

## Задача 43 (с картинкой листьев)

> **43.** Серёжа засушил **2 кленовых и 3 берёзовых листа.** Сколько всего листьев он засушил?

Под задачей — **рисунок листьев**: слева **два кленовых листа** (контурные, с лопастями), справа **три берёзовых листа** (овальные с зубчиками) на веточке.

## 3. Ответы и требования к интерактивным заданиям

№43: 2+3=5 листьев. №44: 4+3=7 яблонь. №46: четыре различных примера a+3, a=1…7, с верным результатом; возможны 1+3=4,2+3=5,3+3=6,4+3=7. №47: 2+3=5 копеек; не 2 монеты как ответ на вопрос о стоимости.

## 5. Интерактивная реализация

Использовать [общие контракты заданий](../INTERACTION_SPEC.md). Для каждого отдельно проверяемого вопроса/примера назначить стабильный ID `p036-exNNN-partNN`; для ненумерованных — `p036-blockNN-partNN`. Числовые ответы вводятся независимо (`number_input`); набор примеров не сводится к одному полю. Текстовые задачи используют `word_problem`, открытое составление — `problem_builder`, счёт предметов — `counting_tap`, разбиение — `group_partition`, таблицы — `table_fill`, рисунок — `draw_canvas`, прописи — `digit_tracing`, палочки — `drag_drop_sticks`. Применять только типы, соответствующие фактическим блокам этой страницы.
