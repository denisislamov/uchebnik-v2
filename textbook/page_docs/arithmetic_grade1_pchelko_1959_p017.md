# Арифметика, 1 класс (Пчёлко, Поляк, 1959) — страница 017

- **Скан страницы:** [page_017.png](../pages/page_017.png)
- **Раздел:** Первый десяток → Число 5 (продолжение) → сложение с 1 в пределах 5
- **Тема страницы:** Задачи по картинкам на сложение (кролики 3 + 1, морковки 4 + 1), схемы с кружками для 1 + 1, 2 + 1, 3 + 1, 4 + 1, образец рукописной записи примеров в тетради, столбики примеров на прибавление 1.
- **Тип страницы:** упражнения / задачи

- **Количество изображений:** 7

## 1. Общее описание

Страница закрепляет запись сложения, введённую на стр. 16. Вверху слева — картинка с кроликами (3 белых и 1 чёрный), справа от неё три вопроса: сколько белых, сколько чёрных, сколько всего. Ниже зеркально: слева три вопроса про морковки, справа картинка (пучок из 4 морковок и 1 морковка отдельно). Кролики: 3 + 1 = 4; морковки: 4 + 1 = 5. В нижней половине слева — четыре прямоугольные рамки с кружками (оранжевые + один зелёный): 1+1, 2+1, 3+1, 4+1; справа от них — фрагмент тетрадного листа в клетку с рукописными записями «1 + 1 = 2», «2 + 1 = 3», «3 + 1 = 4», «4 + 1 = 5» — образец, как писать примеры в тетради. Внизу — шесть примеров на прибавление 1 без ответов, в три колонки по два. Педагогический смысл: переход от предметного счёта к записи и решению примеров «+ 1» в пределах 5.

## 2. Содержимое по порядку (сверху вниз, слева направо)

### Блок 1. Картинка «Кролики»
- **Тип блока:** иллюстрация задачи
- **Текст:** нет
- **Изображение:** [p017_rabbits.png](../images/p017_rabbits.png) — на лужайке с травой, кустиками и одуванчиком (справа) четыре кролика: три белых с чёрными ушами и мордочками (два в середине рядом, один крупный на переднем плане внизу слева, лежит) и один чёрный кролик сидит поодаль вверху справа. Всего 4 кролика: 3 белых + 1 чёрный.
- **Педагогическая функция:** наглядная задача 3 + 1 = 4.
- **Предлагаемая интерактивная реализация:** counting_tap отдельно по белым (3), чёрным (1) и всем (4); подсказка-запись «3 + 1 = 4».

### Блок 2. Вопросы про кроликов
- **Тип блока:** задача (вопросы по картинке)

- **Предлагаемая интерактивная реализация:** три поля pick_number/number_input: 3, 1, 4; после ответа показать запись 3 + 1 = 4.

### Блок 3. Вопросы про морковки

- **Предлагаемая интерактивная реализация:** три поля: 4, 1, 5; запись 4 + 1 = 5.

### Блок 5. Рамки с кружками (4 схемы)
- **Тип блока:** счётная схема
- **Текст:** нет
- **Изображения:**
  - [p017_circles_1_plus_1.png](../images/p017_circles_1_plus_1.png) — прямоугольная рамка, в правой части 1 оранжевый кружок и 1 зелёный. (1 + 1 = 2)
  - [p017_circles_2_plus_1.png](../images/p017_circles_2_plus_1.png) — рамка: 2 оранжевых + 1 зелёный. (2 + 1 = 3)
  - [p017_circles_3_plus_1.png](../images/p017_circles_3_plus_1.png) — рамка: 3 оранжевых + 1 зелёный. (3 + 1 = 4)
  - [p017_circles_4_plus_1.png](../images/p017_circles_4_plus_1.png) — рамка: 4 оранжевых + 1 зелёный. (4 + 1 = 5)

- **Педагогическая функция:** наглядная модель каждого примера «n + 1»: оранжевые — первое слагаемое, зелёный — прибавляемая единица.
- **Предлагаемая интерактивная реализация:** каждая рамка связывается с соответствующей записью справа; ученик нажимает на кружки, считая, затем выбирает ответ. Можно давать ученику самому «добавить зелёный кружок» (drag_drop).

- **Педагогическая функция:** показать, как записывать примеры в тетради (по клеткам).
- **Предлагаемая интерактивная реализация:** digit_tracing / expression_tracing — обведение записи по клеткам; либо просто образец, показываемый при задании «запиши».

## 5. Типы интерактивности, которые нужны на этой странице

- counting_tap (кролики, морковки, кружки)
- pick_number / number_input (ответы на вопросы «сколько»)
- word_problem (задача по картинке с тремя вопросами и итоговой записью)
- expression_input (шесть примеров «n + 1 =»)
- digit_tracing / expression_tracing (обведение рукописного образца записи по клеткам)
- read_aloud

## 6. Замечания для реализации

- Страница опирается на стр. 16 (знаки «+», «=»). Здесь впервые показан рукописный образец записи примера в тетради — в приложении желательно режим «тетрадь в клетку».
- В четырёх рамках кружки выровнены по правому краю, зелёный кружок обозначает «+ 1» — эту цветовую логику стоит сохранить.
- Внизу слева стоит типографская сигнатура «2 Арифметика, I кл.» — служебная надпись, в приложение не переносится.
- Кролики пересчитаны: 3 белых + 1 чёрный; морковки: 4 в пучке + 1 отдельно = 5.
- Все тексты читаются полностью; неразборчивых фрагментов нет.
