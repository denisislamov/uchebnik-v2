- **Тип страницы:** учебная; объяснение / упражнения / практические задания (состав блоков ниже).

## 1. Общее описание и порядок чтения

Материал читается сверху вниз, в пределах ряда слева направо. Тема: Начало вычитания с переходом через десяток: 11−2. Порядок блоков и состав иллюстраций приведены ниже. Исходные вопросы, образцы с готовым ответом и задания с пустыми полями должны оставаться разными элементами интерфейса. Печатный номер страницы — 84, внизу слева.

## 2. Содержимое страницы

### 409. Счёт группами
«Считайте тройками до 18. Считайте четвёрками до 20.»
### 410. Кормушка
«Дети устроили кормушку для птиц. К кормушке прилетели 7 воробышков, а синичек на 5 больше. Сколько всего птичек прилетело к кормушке?»
### 411. Составление
«Составьте задачу, похожую на предыдущую, но с другими числами, и решите её.»
### 412. Примеры
```
3+4+9  18−4−3  7+8−4
10−4+8 19−5−2  9+7−5
9−5+7  20−3−6  4+7+8
```
### Заголовок
«Вычитание с переходом через десяток.»
### 413. До десяти
«Сколько нужно отнять от 11, чтобы получить 10?»
### 414. Примеры
```
7−1  11−1−1  11−1−2  11−1−7
5−1  11−1−3  11−1−4  11−1−5
```
### 415. Палочки
«Положите на парту 1 десяток палочек и 1 палочку. Возьмите из них 2 палочки и положите их в коробку. Сколько палочек останется на парте?»
### 416. Счёты
«Отложите на счётах 11 косточек. Отнимите 2 косточки. Сколько косточек останется?» Под условием не палочки, а рамка с кружками: слева 10 (5+5), справа 1; зачёркнуты правый одиночный и крайний нижний слева. Образец «11−2=», ниже «11−1=10», «10−1=9».
### 417. Примеры
```
11−3  11−4  11−9
11−5  11−6  11−7
```

## 3. Ответы и требования к интерактивным заданиям

№409: 3,6,9,12,15,18;4,8,12,16,20. №410: 7+5=12 синичек;7+12=19 птиц. №411: новый сюжет с a и a+b, итог 2a+b≤20; взрослый оценивает связность. №413: 1. №415 и №416: 11−2=9. Анимация: убрать единицу вне десятка, раскрыть десяток, убрать ещё одну. Историческое название «косточки» относится к счётам; рисунок — абстрактная схема.

## 5. Интерактивная реализация

Использовать [общие контракты заданий](../INTERACTION_SPEC.md). Для каждого отдельно проверяемого вопроса/примера назначить стабильный ID `p084-exNNN-partNN`; для ненумерованных — `p084-blockNN-partNN`. Числовые ответы вводятся независимо (`number_input`); набор примеров не сводится к одному полю. Текстовые задачи используют `word_problem`, открытое составление — `problem_builder`, счёт предметов — `counting_tap`, разбиение — `group_partition`, таблицы — `table_fill`, рисунок — `draw_canvas`, прописи — `digit_tracing`, палочки — `drag_drop_sticks`. Применять только типы, соответствующие фактическим блокам этой страницы.
