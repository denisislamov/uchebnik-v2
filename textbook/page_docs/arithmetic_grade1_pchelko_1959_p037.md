## 1. Общее описание

Страница целиком текстовая, без иллюстраций. Это продолжение темы «Прибавить и отнять 3» (заголовок находится на предыдущей странице). Сверху две текстовые задачи на сложение с числом 3 (№ 48 — покупка альбома и книги, № 49 — составить задачу «к 1 прибавить 3»). Далее два больших столбика примеров (№ 50, 51) по 4 колонки × 4 строки, где сложение с 3 перемешано с повторением +1, −1, +2, −2. В середине страницы три задачи (№ 52–54) вводят выражение **«столько же»** (выделено жирным шрифтом): к числу прибавить такое же число. Затем ещё столбик примеров № 55 (сложение с 3 и вычитание 1, 2), столбик № 56 на вычитание двух чисел подряд (4−2−1, 5−1−2 …) — подготовка к вычитанию 3 по частям, которое разбирается на следующей странице. Внизу практическое задание № 57 с кружками (4 − 3), непосредственно подводящее к теме «отнять 3». Педагогический смысл: закрепить сложение с 3, ввести «столько же», подготовить вычитание 3 через вычитание по частям.

## 2. Содержимое по порядку (сверху вниз, слева направо)

### Блок 1. Задача № 48
- **Тип блока:** задача
- **Текст (дословно):** «48. Мама купила Наде к празднику альбом за 5 рублей и книгу за 3 рубля. Сколько денег уплатила мама за эту покупку?»
- **Изображение:** нет
- **Педагогическая функция:** текстовая задача на сложение с 3 (5 + 3) в бытовой ситуации с деньгами (рубли).
- **Предлагаемая интерактивная реализация:** текст задачи озвучивается; ученик выбирает действие (+/−) и вводит ответ. Проверка: 5 + 3 = 8 (рублей). Можно показать монеты/купюры как подсказку (необязательно, в книге картинки нет).

### Блок 2. Задача № 49
- **Тип блока:** задача (составить задачу)
- **Текст (дословно):** «49. Составьте задачу, в которой нужно к одному рублю прибавить 3 рубля.»
- **Изображение:** нет
- **Педагогическая функция:** творческое задание — придумать сюжет для примера 1 + 3 = 4.
- **Предлагаемая интерактивная реализация:** открытый ответ. Вариант: конструктор задачи из заготовок (кто? что купил? за сколько?) с фиксированными числами 1 и 3; итоговая проверка — ученик вводит ответ 4. Либо запись голосом/текстом с проверкой по критериям: в тексте есть числа 1 и 3, слово «рубль», вопрос «сколько всего».

### Блок 3. Примеры № 50
- **Тип блока:** примеры (4 колонки × 4 строки)
- **Текст (дословно):**
  ```
  50. 3+1   4+3   9+1   8+2
      1+3   6+3   8−1   6−2
      3+2   5+3   7−1   7−2
      2+3   7+3   9−1   9−2
  ```
- **Изображение:** нет
- **Педагогическая функция:** колонки 1–2 — сложение с 3 (включая перестановку слагаемых 3+1 / 1+3), колонки 3–4 — повторение ±1, ±2.
- **Предлагаемая интерактивная реализация:** поочерёдный ввод ответов (number_input) по колонкам, с мгновенной проверкой.

### Блок 4. Примеры № 51
- **Тип блока:** примеры (4 колонки × 4 строки)
- **Текст (дословно):**
  ```
  51. 1+3   5+3   6−1    8−2
      4+3   7+3   9−1    5−2
      3+3   4+3   7−1    9−2
      2+3   6+3   10−1   7−2
  ```
- **Изображение:** нет
- **Педагогическая функция:** та же структура, что № 50 — закрепление.
- **Предлагаемая интерактивная реализация:** number_input; можно как «тренажёр на время».

### Блок 5. Задача № 52
- **Тип блока:** практическое задание (с палочками)
- **Текст (дословно):** «52. Положите 3 палочки слева и **столько же** палочек справа. Сколько всего палочек получится?» (слова «столько же» набраны жирным)
- **Изображение:** нет
- **Педагогическая функция:** введение термина «столько же» = такое же количество; 3 + 3 = 6.
- **Предлагаемая интерактивная реализация:** экран с двумя зонами (слева/справа); ученик перетаскивает 3 палочки влево, затем «столько же» вправо (drag_drop_sticks), после чего вводит общее число. Проверка: справа ровно 3, ответ 6.

### Блок 6. Задача № 53
- **Тип блока:** задача
- **Текст (дословно):** «53. Для детского сада купили сначала 3 лейки, а потом ещё **столько же**. Сколько всего леек купили?»
- **Изображение:** нет
- **Педагогическая функция:** «столько же» в текстовой задаче; 3 + 3 = 6.
- **Предлагаемая интерактивная реализация:** word_problem — ученик сначала указывает, сколько это «столько же» (3), затем вводит ответ 6.

### Блок 7. Задача № 54
- **Тип блока:** задача
- **Текст (дословно):** «54. Для школы купили сначала 2 молотка, а потом ещё **столько же**. Сколько всего молотков купили?»
- **Изображение:** нет
- **Педагогическая функция:** то же; 2 + 2 = 4.
- **Предлагаемая интерактивная реализация:** word_problem, ответ 4.

### Блок 8. Примеры № 55
- **Тип блока:** примеры (4 колонки × 4 строки)
- **Текст (дословно):**
  ```
  55. 4+3   5−1   6−2    9−2
      6+3   8−1   8−2    7−1
      5+3   4−1   7−2    10−2
      7+3   9−1   10−2   8−1
  ```
- **Изображение:** нет
- **Педагогическая функция:** сложение с 3, вычитание 1 и 2 — база для вычитания 3 по частям.
- **Предлагаемая интерактивная реализация:** number_input.

### Блок 9. Примеры № 56
- **Тип блока:** примеры (2 строки × 4 примера, вычитание двух чисел подряд)
- **Текст (дословно):**
  ```
  56. 4−2−1   6−2−1   8−2−1   10−2−1
      5−1−2   7−1−2   9−1−2   10−1−2
  ```
- **Изображение:** нет
- **Педагогическая функция:** вычитание 3 по частям (2 и 1, 1 и 2) — подготовка к следующей странице «отнять 3».
- **Предлагаемая интерактивная реализация:** двухшаговый ввод: сначала промежуточный результат (например 4−2 = 2), затем итог (2−1 = 1); или сразу итог.

### Блок 10. Задача № 57
- **Тип блока:** практическое задание (с кружками)
- **Текст (дословно):** «57. Положите на парту 4 кружка. Возьмите 3 кружка и положите их в коробку. Сколько кружков осталось на парте?»
- **Изображение:** нет
- **Педагогическая функция:** предметное введение вычитания 3: 4 − 3 = 1. Переход к схемам на стр. 38.
- **Предлагаемая интерактивная реализация:** на экране 4 кружка и коробка; ученик перетаскивает 3 кружка в коробку (drag_drop), затем считает оставшиеся и вводит 1.

### Блок 11. Номер страницы
- **Тип блока:** служебный элемент
- **Текст:** «37» (внизу справа)

## 5. Типы интерактивности, которые нужны на этой странице

- word_problem — текстовая задача с вводом ответа (48, 53, 54).

- number_input — столбики примеров (50, 51, 55, 56).

## 6. Замечания для реализации

- Заголовок темы «Прибавить и отнять 3» находится на предыдущей странице (36); страница 37 — её продолжение.
- Слова «столько же» в № 52–54 набраны жирным — в приложении выделять и, желательно, давать всплывающее пояснение («столько же — такое же число»).
- Задачи с деньгами (№ 48, 49) используют рубли образца 1959 г.; для приложения сумму можно не визуализировать.
- № 56 — важный подготовительный блок для стр. 38 (вычитание 3 как −1−1−1 и −2−1); желательно реализовать с показом промежуточного результата.
- OCR-текст страницы совпадает со сканом; неразборчивых фрагментов нет. Орфография книги: «ещё», «Составьте».
